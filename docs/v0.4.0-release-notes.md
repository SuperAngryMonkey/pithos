# Pithos v0.4.0 Release Notes

**Template choice.** Pithos no longer assumes a single template at VMID 9000.

## What's new

- **Template enumeration** — every template on the host is discovered, LXC and
  VM alike, each tagged with `kind` (`lxc` or `vm`), `os`, and its description.
- **`GET /api/templates`** — the list as JSON, for the MCP and scripted clients.
- **A TEMPLATE picker** in the clone form, defaulting to `TEMPLATE_VMID`.
- **`pithos-new --template <vmid>`** (and the existing `TEMPLATE_VMID` env).
- **Server-side validation** — an unknown template, or a VM template submitted
  by a crafted request, is refused with a clear message rather than failing
  deep inside `pct clone`.

## VM templates are listed but not provisionable

Windows and other VM templates appear in the picker, marked and disabled.
Cloning them needs `qm clone` plus a cloud-init drive rather than `pct clone`
plus `pct exec`, which is a separate piece of work.

Listing them now is deliberate: the enumeration, the `kind` field and the
picker are the plumbing that VM provisioning will use, and having them in place
makes that change additive rather than structural.

## Files changed

- `webui/app.py` — enumeration, `/api/templates`, picker, validation
- `scripts/pithos-new.sh` — `--template` flag
